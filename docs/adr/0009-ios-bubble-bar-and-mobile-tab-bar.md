# ADR-0009 — 选中泡泡栏与移动端底部 Tab 栏

- **状态**：已采纳（Accepted）
- **日期**：2026-07-31
- **决策人**：产品（注重体验）/ CodeBuddy

> **注意（部分取代）**：本 ADR 的**视觉风格决策**（iOS 毛玻璃泡泡栏、Apple 霜化玻璃顶栏）已被 **ADR-0012** 取代，改为「沉静编辑式」视觉语言。本 ADR 的**功能决策仍然有效**：浮动泡泡栏作为选中操作面、移动端底部 Tab 栏作为主入口、不新增全选 / 分享——仅在其新视觉语言下重绘。

## 背景

当前选中文字弹出的是「操作菜单」（垂直列表气泡，见 `ActionSheet.vue`），顶部工具栏在窄屏会换行拥挤。
产品目标：参考最新 iOS 的文字选中浮动泡泡栏（callout）与 Apple 网页设计语言，重做选中工具与顶栏，并让移动端真正可用。

设计评审（grilling）中明确了三个关键取舍：

1. **选中工具的形态与内容**
   用户确认：形式参考 iOS 浮动泡泡栏，但**内容保持现状**——即保留 LLM 快捷操作 + 复制 + 取消，
   **不新增**「全选 / 查找 / 分享」等按钮。泡泡栏是现有操作菜单的视觉重做，而非功能扩张。
2. **移动端顶栏**
   用户选择「底部 Tab 栏」：移动端把主要入口下沉到屏幕底部的 iOS 风格 Tab 栏，
   顶部仅保留文件名与主题切换。桌面端顶栏保持完整功能但改为 Apple 霜化玻璃风格。
3. **全选 / 分享**
   用户明确「不需要做全选」，且不新增分享。因此本次不实现这两项。

## 决策

### 1. 选中工具 = 浮动泡泡栏（内容不变）
- `ActionSheet.vue` 改造为 iOS 风格的水平浮动泡泡栏：圆角胶囊、指向选中文字的小箭头、毛玻璃质感。
- 桌面端为「图标 + 文字」横向排列，溢出可横向滚动；移动端（≤640px）为「仅图标」胶囊行（与现有移动规则一致，避免与底部抽屉争抢）。
- **移除**原有的选中文字预览（quote）——iOS callout 不显示它，选中高亮本身已提供上下文，保持界面干净。
- 内容完全不变：拷贝、各 LLM 快捷操作（含自定义）、取消。
- z-index 提升至 160，确保位于搜索栏（120）与面板抽屉（130）之上。

### 2. 顶栏改为 Apple 霜化玻璃风格（桌面）
- 半透明 + `backdrop-filter: saturate(180%) blur(20px)`，细分割线，系统字体，留白充裕。
- 激活态用品牌蓝填充胶囊；按钮圆角统一。功能不变：打开 / 文件名 / 目录 / 搜索 / 对话 / 缩放 / 跳页 / 主题 / ⌘K / 设置。

### 3. 移动端底部 Tab 栏（≤768px）
- 顶栏精简为：品牌 + 文件名（左）、主题切换（右）。
- 新增 `BottomTabBar.vue`，固定底部，iOS 风格（图标 + 文字标签），含安全区 `env(safe-area-inset-bottom)`。
- Tab 项：打开、目录、搜索、对话、设置。分别绑定 `reader.loadFile` / `ui.toggleOutline` / `ui.openSearch` / `ui.toggleConversation` / `ui.openSettings`。
- 层级：scrim 120 < Tab 栏 125 < 面板抽屉 130，使打开的抽屉能覆盖 Tab 栏（符合 iOS modal sheet 行为）。
- ⌘K 命令面板为桌面键盘特性，移动端不进 Tab 栏。

### 4. 术语（更新 `CONTEXT.md`）
- 「操作菜单」补充说明其视觉形态为**浮动泡泡栏**。
- 新增「底部 Tab 栏」词条，描述移动端主入口的下沉布局。

## 替代方案（被否定）

- **泡泡栏即全部（删掉 LLM 快捷操作）**：会削弱产品核心价值「选中即理解」，否决。
- **两层并存分触发（轻点=泡泡栏，长按=操作菜单）**：交互复杂、可发现性差，否决。
- **移动端顶栏仅做视觉简化（不引入 Tab 栏）**：未解决窄屏拥挤，否决。
- **实现「全选 / 查找 / 分享」**：用户明确不需要全选、不新增分享，否决。

## 影响

- `Toolbar.vue`、`ActionSheet.vue`、新增 `BottomTabBar.vue`、`App.vue`、`style.css`、`index.html`。
- 不改变任何业务逻辑、存储或 API 调用；纯界面与交互层改动。
