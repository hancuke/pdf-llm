# 单词音标使用外部词典 API（偏离纯客户端原则的有意取舍）

朗读面板的「点击单词显示音标」功能，英文音标（IPA）取自外部免费词典 API（如 dictionaryapi.dev），而非本地打包词典；本期仅做英文，不做中文音标。

这与 `ADR-0001`（纯浏览器端、不上传、无自有后端）的调性相悖——每次点词都会向第三方发请求、泄露"用户查了哪个词"。之所以接受这一偏离：本地英文 IPA 词典需打包数百 KB，而音标仅为辅助功能、非核心；用外部 API 把包体压到最小，且 TTS 合成本就已依赖网络端点，用户对此类网络依赖已有预期。单词**发音**仍走本地 TTS 代理（见 `tts.ts`），不依赖该 API，避免发音能力被 API 可用性牵制。
