# ADR-0016 — 生词本是独立于书签的持久化收藏（存词与语境，仅留浏览器）

朗读「词汇卡」需要「收藏」落点。现有 `书签` 模型只存页码 + 滚动位置、不含任何文档文字（CONTEXT.md「书签」/ ADR-0004），但生词本的价值恰在保存用户选中的**词与语境句**。ADR-0001 仅禁止上传，允许标注留浏览器。因此新增独立的**生词本** store，刻意偏离 `书签` 的「不存文本」约束。

**Considered Options**
- 复用 `书签`：受「不存文本」约束，无法存词，等于不做收藏 —— 未采纳。
- 新增独立 `生词本` store：存词条（词、音标、语境句、来源文档、页码、时间），仅留 localStorage —— **采纳**。
- 本轮不做收藏：留作后续 —— 未采纳（会使词汇卡差异化落空）。

**Consequences**
- `生词本` 与 `书签` 并存，语义不同（位置记忆 vs 词汇收藏），须在术语与 UI 上明确区分，避免混淆。
- 生词本文本**仅留浏览器**（localStorage），不上传任何服务器，与 ADR-0001 一致；不在「文档与标注不上传」之外新增任何外发。
- 新增一个浏览表面：桌面为可折叠面板、移动端下沉为底部 Tab 栏入口，与 目录/对话 并列（见 CONTEXT.md「面板」「底部 Tab 栏」）。
- 未来若做导出/同步，须仍是浏览器内或用户显式触发，不得自动外发。
