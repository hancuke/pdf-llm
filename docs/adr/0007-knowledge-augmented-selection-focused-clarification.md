# 知识增强的选中聚焦澄清

本项目的 PDF 均为公开资料，LLM 训练时大概率已见过全文；用户要的是"只针对选中的那部分，用更易理解的方式搞懂它"，而非整篇问答。因此将 LLM 的核心定位从原 spec 的"严格基于段落文本的复述器"改为「选中聚焦型澄清」：Context 仅发送 `干净题目 + 选中内容所在整段`；明确允许模型借助其对本文的潜在全文认知与通用知识（类比、举例、关联）来解释，但焦点永远是选中内容；以提供的段落为硬锚，模型知识仅作补充，且不确定时必须声明"以下仅基于你给出的文本"；另设全局「讲解风格」开关（默认 / 通俗大白话 / 小学生级）。

这是一个难逆转且反直觉的决定：它推翻了原 spec"严格基于段落文本"的隐含假设，并把 context 配方与 system prompt 锁死——后续若改回"纯文本复述"需重写提示词与测试。值得记录，是因为一个未来读者看到"明明模型可能已训练过全文、却不发给它，反而鼓励用训练记忆"会大惑不解；本 ADR 说明这是刻意为之，依赖"公开资料 + 模型已训练过"的前提。代价：若模型实际未训练过该文档，会落到不确定性声明分支，解释质量下降。
