# ADR-0017 — 设置面板重构为 macOS 式侧栏 + 即时应用

- **状态**：已采纳（待实现）
- **日期**：2026-08-02
- **决策人**：产品 / CodeBuddy（grilling 会话）

## 背景与决策

当前 `SettingsPanel.vue` 是一个单屏滚动的居中模态：分组卡片 + 分段控件 + 显式保存（draft + `保存/取消` 页脚 + dirty 追踪）。其头部注释仍称沿用「iOS 设计语言（毛玻璃表头）」，但与 **ADR-0012** 已采纳的「沉静编辑式」视觉语言（禁用 `backdrop-filter`）冲突。grilling 会话决定以成熟产品为锚重做设置面板，使其更「production-grade」且自洽。

### 决策

1. **锚点 = macOS 系统设置**：桌面端为右侧滑出面板（PDF 留在背后 scrim 中），内部左栏分类 + 右栏详情；移动端（≤768px）沿用底部抽屉外壳，改为 iOS 式下钻（分类列表 → 详情，带返回）。
2. **保存模型 = 即时应用（immediate-apply）**：改动即时写入 `localStorage`，移除 draft、`保存/取消` 页脚与 dirty 追踪。保留「测试连接」作为端点连通性守卫（不靠「取消」来防误写）。
3. **分类 = 4 项**：`通用`（外观 + 外部请求/隐私） / `模型服务`（服务端点） / `朗读` / `动作`（自定义动作）。将单薄的「外部请求」并入「通用」，避免孤立薄项。
4. **不加设置内搜索**，隐私保持最简（切换留在「通用」，不加侧栏底部说明）。
5. **视觉遵循 ADR-0012「沉静编辑式」**：靛蓝 `#5B5BD6` 选中态、柔和分层阴影 + 1px 发丝边、**不使用毛玻璃**；纠正当前面板的 iOS 毛玻璃注释。

## 替代方案（被否定）

- **iOS 分组列表（下钻）作为桌面主形态**：移动端采用，但桌面端单屏滚动不如侧栏「专业」且贴合锚点，否决。
- **VS Code / Linear 式可搜索扁平列表**：適合高级用户，但与「沉静编辑式 + macOS 锚点」不符，且设置项仅 ~15 个，收益有限，否决。
- **保留显式保存 / 混合（端点组显式）**：即时应用更贴合 macOS 锚点、更简洁；本地数据可随时重编辑，「取消」价值低，否决。
- **整页路由呈现**：离开阅读上下文、打断阅读，否决。

## 影响（待实现）

- 重构 `SettingsPanel.vue`：侧栏 + 详情结构；桌面右滑出、移动下钻；移除 draft/页脚/dirty 逻辑。
- `stores/settings.ts`：现有逐字段 `update*`/write-through action 可直接复用，`applyDraft` 与 dirty 路径移除。
- `BottomTabBar.vue` / `ui` store 的「设置」打开态适配新形态。
- 不改变业务逻辑、存储键或 API 调用；纯界面与交互层改动，且须对齐 ADR-0012 令牌。
