# ADR-0013 — 隐私披露口径：文档不上传，但选中片段走功能 API 为有意可控偏离

- **状态**：已采纳（Accepted）
- **日期**：2026-08-02
- **决策人**：产品（注重体验）/ CodeBuddy

## 背景与决策

早期口径声称"文档与标注始终只存在于浏览器、不会上传到任何服务器、绝对没有任何东西离开浏览器"。该口号**过于绝对且与事实冲突**：为提供「朗读」与「音标」，选中内容的**片段**已发往第三方功能接口（TTS 代理、外部词典 API，见 ADR-0011）。

grilling 会话确定修订口径，明确区分两个不同概念：

- **文档与标注不上传**：PDF 字节、解析结果、用户标注不离开本机，无自有后端——**ADR-0001 的核心不变**。
- **选中片段走功能 API**：为「朗读」「音标」等功能，选中内容的片段会发往对应第三方接口；这是对"纯客户端"的**有意、可控偏离**（沿用 ADR-0011 + `tts.ts`），**不构成"上传文档到服务器"**。

落地方式：

- **空状态移除**"不上传"绝对口号（不再做该承诺）。
- **设置中披露并可开关**：对「朗读」「音标」显式列出其外部请求并给开关，用户可选择退出外发。
- CONTEXT.md 顶部隐私句改为上述修订口径（见 CONTEXT.md）。

## 为何不维持原口号

原口号与运行行为不符，会损害而非增强信任。诚实披露 + 可退出，反而巩固产品"本地优先"的立身之本：我们依然不持有你的文档，只是某些功能的选中片段需借助外部接口，且你可控。

## 影响

- CONTEXT.md 顶部隐私表述修订；设置面板新增「朗读 / 音标」外部请求的披露与开关。
- 不新增自有后端、不改变文档 / 标注的本地存储（ADR-0001 不变）。
- 与 ADR-0011 协同：ADR-0011 记录"音标走外部词典"的技术取舍，本 ADR 记录"该偏离须在界面如实披露且可退出"的产品原则。
