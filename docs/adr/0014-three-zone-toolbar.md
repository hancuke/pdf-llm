# ADR-0014 — 三区式图标工具栏（移动端适配）

- **状态**：已采纳（Accepted）
- **日期**：2026-08-02
- **决策人**：产品（注重体验）/ CodeBuddy

## 背景

`Toolbar.vue` 原始实现为 4 组纯中文文字按钮（打开 / 目录 / 搜索 / 对话 / 缩放 / 跳页 / 主题 / ⌘K / 设置），窄屏靠 `.tb-hide-mobile` 整组隐藏。这导致：

1. 移动端（≤768px）完全没有页码与跳页能力——底部 Tab 栏只承载导航入口，不承载阅读位置。
2. 文字按钮占宽大，900px 就开始隐藏控件。
3. 跳页输入框与「第 N 页」读数职责重复。
4. 缩放只有 ±，缺少读论文最高频的「适合宽度/适合页面」。

业内成熟 PDF 阅读器（PDF.js、Chrome PDF、Zotero、Acrobat）均采用**三区式图标工具栏**：左=文档身份+面板开关，中=阅读位置+缩放，右=工具+外观；按钮为图标 + tooltip/aria-label。

## 决策

### 1. 三区布局

顶栏分为 `.tb-left / .tb-center / .tb-right` 三区：
- 左区：品牌方块 + 目录开关 + 打开 + 文档标题
- 中区：翻页 + 页码字段（合并原 `goto` 与 `current-page`）+ 缩放组
- 右区：搜索 + 对话 + 主题切换 + ⌘K + 设置

### 2. 图标为主 + tooltip

所有操作按钮改为 20px 线性 SVG 图标（与 BottomTabBar 同一套画法），每个带 `title`（tooltip）+ `aria-label`；面板开关类按钮额外带 `aria-pressed`。⌘K 保留文字胶囊形态（自解释）。

### 3. 渐进降级（不再整组消失）

| 宽度 | 收起的项 |
| --- | --- |
| ≤1024px | ⌘K |
| ≤900px | 翻页键（页码输入仍在） |
| ≤768px | 目录、打开、缩放组、搜索、对话、设置 → 全部由底部 Tab 栏承担 |

### 4. 移动端顶栏 = 标题 + 页码 + 主题

移动端顶栏不再仅保留文件名与主题切换（ADR-0009 第 2 条的原始表述），而是增加页码指示与跳页能力。底部 Tab 栏仍为导航入口（打开/目录/搜索/对话/设置），两者零重复。

### 5. 缩放预设菜单

点击百分比标签展开下拉菜单：适合宽度 / 适合页面 / 自动 / 50%–200%。当前项打勾。通过 `viewer.ts` 新增的 `setZoomLevel` / `getZoomLevel` 桥接到 EmbedPDF 的 `ZoomMode` 枚举。

### 6. 视觉语言

遵循 ADR-0012 的沉静编辑式令牌（stone/zinc 底色 + 靛蓝强调色 + 发丝边 + 中等圆角）。样式全部落在 `<style scoped>` 内，不污染全局 CSS。

## 部分修订 ADR-0009

本 ADR **修订** ADR-0009 第 2 条关于移动端顶栏的描述（从「仅保留文件名与主题切换」扩展为「文件名 + 页码 + 主题」），并取代其视觉风格决策（已由 ADR-0012 统一接管）。ADR-0009 的功能决策（浮动泡泡栏、底部 Tab 栏入口列表、不加全选/分享）仍然有效。

## 替代方案（被否定）

- **保持纯文字按钮**：窄屏无法容纳，否决。
- **移动端顶栏加搜索/更多菜单**：与底部 Tab 重复且可发现性无增益，否决。
- **自动隐藏顶栏**：复杂度上升明显，本轮不做，否决。
