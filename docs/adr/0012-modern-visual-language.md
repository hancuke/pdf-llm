# ADR-0012 — 视觉语言转向「沉静编辑式」

- **状态**：已采纳（Accepted）
- **日期**：2026-08-02
- **决策人**：产品（注重体验）/ CodeBuddy

## 背景与决策

本轮 UI 重设计（grilling 会话确定）放弃对 iOS 设计语言的模仿，采用自研的现代视觉语言**「沉静编辑式 / Calm Editorial」**。依据如下：

- 产品定位是"读文献 + 借 LLM 理解"，核心活动是阅读与专注，喧闹的视觉与反目标冲突；
- 现有 iOS 毛玻璃 / Apple 霜化玻璃风格被明确释放（见下方对 ADR-0009 的部分取代）；
- "现代化"来自克制而非花哨，与"产品化"目标一致。

视觉语言具体约定：

- **配色**：中性灰阶（stone/zinc 调）为底，光 / 暗双主题一等公民；单一克制强调色 **靛蓝 `#5B5BD6`**，仅用于主操作与选中态。
- **字体**：界面用 Inter / 系统无衬线；文档区沿用 PDF 自身字体（不改）。
- **层级**：用**柔和分层阴影 + 1px 发丝边**取代毛玻璃（`backdrop-filter` 几乎不用）。
- **圆角**：中等（10–14px），现代但不卡通。
- **动效**：短（150–200ms）、有目的（面板滑入、气泡淡入），无多余装饰。
- **密度**：舒适留白，不拥挤；暗色模式是设计的一部分而非后加。

## 部分取代 ADR-0009

本 ADR **仅取代 ADR-0009 的视觉风格决策**（iOS 毛玻璃泡泡栏、Apple 霜化玻璃顶栏）。ADR-0009 的**功能决策仍然有效**：浮动泡泡栏作为选中操作面、移动端底部 Tab 栏作为主入口、不新增全选 / 分享。即在新视觉语言下重绘这些控件，功能形态不变。

## 替代方案（被否定）

- **中性效率式（Linear/Notion 风）**：更冷峻紧凑，但阅读氛围弱，否决。
- **表现型微玻璃（Expressive Glass）**：保留并升级毛玻璃、加活力渐变，易干扰专注，且与"沉静"目标冲突，否决。

## 影响

- 涉及 `Toolbar.vue`、`ActionSheet.vue`、`BottomTabBar.vue`、`SettingsPanel.vue`、`ReadAloudPanel.vue`、`ConversationPanel.vue`、`style.css` 等全部界面与令牌体系。
- 不改变业务逻辑、存储或 API 调用；纯视觉与令牌层改动。
- 设计令牌（颜色 / 圆角 / 阴影 / 动效）应集中定义，作为后续组件换肤的统一基底。
