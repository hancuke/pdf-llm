# 选择性客户端持久化：导航状态持久化，摘录与对话不持久化

用户创建的**书签**（仅页码+滚动位置）、每文档的**上次阅读位置**、主题与面板显隐偏好写入 `localStorage` 跨刷新保留；文档字节、选中内容摘录与对话历史**仍不持久化**（延续 ADR-0001 / ADR-0004）。

理由：书签与阅读位置只包含"用户在文档中的坐标"，不含任何文档文字或对话内容，因此没有 ADR-0004 所担心的敏感摘录留存风险，却显著提升了"像产品"的体验（重开即续读、随时回到某页）。这是一次真实的取舍——我们刻意把"持久化"按数据敏感度分层：坐标类状态可持久化，内容类状态不可。未来若有人想"顺便把高亮/对话也存下来"，必须回到本 ADR 重新决策，而非在书签存储旁边悄悄扩展。
