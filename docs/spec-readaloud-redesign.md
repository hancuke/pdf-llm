# Spec: 「朗读」交互与 UI 重设计

## Problem Statement

现有「朗读」功能技术可用，但交互与成熟听书 / Read-Aloud 产品差距明显：语速与音色深埋设置（比 Edge / Play Books 深两层）；传输条只有整段重播，无逐句跳、无面内语速/音色；关掉底部弹层即停，用户无法边浏览边听；音标 + 单词语音这一独家差异化能力只缩在一个事后 popover 里，没被抬高。整体仍像「能用」而非「产品化」。

本轮由产品定位收敛为：**选区作用域的「随听」**，对齐 LLM「选中聚焦」核心（ADR-0015、CONTEXT.md）。据此重设计交互与 UI，借鉴成熟产品的播放器范式，但**不做音频同步高亮**（ADR-0015）。

## Benchmark 提炼的范式（成熟产品）

Edge Read Aloud / Immersive Reader（工具条 + 当前句高亮 + 句跳转 + 图文词典）、Google Play Books（自然嗓音 + 语速 + 跳转）、微信读书 / Kindle 听书（语速 + 定时关闭 + 收藏句子）、Audible（睡眠定时 + 常驻迷你条）、NaturalReader / Speechify（极简播放器 + 取词）。共同范式：**播放/暂停 + 语速 + 音色 + 常驻迷你条 + 取词查义**。本应用额外独有：**点词查音标 + 单词语音**。

## Solution — 交互模型

选区作用域「随听」：用户在 PDF 选中文字 → 操作菜单触发「朗读」→ 朗读面板出现并开始播放选区。面板可收起为迷你播放器继续播，用户边读 PDF / 借 LLM 理解边听。点面板内任意词 → 词汇卡（音标 + 发音 + 收藏）。全链路沿用「沉静编辑式」视觉语言（ADR-0012）。

### 组件 1 — 朗读面板（Read-Aloud Panel）

底部弹层，分三部分：

- **传输条（两行）**
  - 第一行：`↺ 重播` · `▶ / ❚❚ 播放暂停` · `进度条（可拖拽 seek）` · `当前时间 / 总时长`
  - 第二行（控制）：`朗读语速`（−/＋ 档位，如 0.5×–3×）· `朗读音色`（芯片，点开音色抽屉选晓晓/云希/Emma…）· `⋯更多`（音调滑块、下载、睡眠定时）
  - 依据 ADR-0015：**无** ⏮/⏭ 句跳（无句边界时间戳）。
- **朗读文字视图**：选区原文按词切分为「词单元」，静态、可点击；刻意不与播放进度同步（ADR-0015）。
- **词汇卡（点词弹出）**：单词 + IPA 音标（外部词典 API，ADR-0011）+ 自动单词语音（TTS 重合成，CONTEXT「单词发音」）+ 收藏按钮 → 写入「生词本」（详见 `docs/spec-vocab-book.md`、ADR-0016）。
- 关闭：✕ / Esc / 点外部（沿用 spec-ui-redesign 故事 13）；移动端不遮底部 Tab 栏（故事 14）。

### 组件 2 — 迷你播放器（Mini Player）

朗读面板收起后保留的常驻细条：显示「正在朗读：{选区前若干字…}」、暂停 / 停止、点按展开回朗读面板。让用户边浏览 PDF 边听。受纯浏览器标签限制，不做后台 / 锁屏播放（CONTEXT「迷你播放器」）。

### 组件 3 — ⋯更多 抽屉

从传输条第二行 `⋯` 展开：朗读音调（pitch）滑块、下载语音（复用 `download`，文件名见 `buildReadAloudFileName`）、睡眠定时（选 5/10/15/30/60 分钟或关闭，到点 `stop`）。

## 状态覆盖（复用四态约定，见 spec-ui-redesign）

- **合成中（loading）**：传输条主按钮转「停止」，可取消（已有 `isSynthesizing`）。
- **错误（error）**：显示 `ttsError`（网络 / 端点失败），提供重试。
- **外部请求关闭（disabled-external，ADR-0013）**：设置关掉朗读/音标外部请求时，触发朗读或点词均拦截并 toast 说明，不静默发请求。
- **空选区**：未选中文字时操作菜单不出现「朗读」（朗读始终选区作用域）。

## Out of Scope（本轮不做）

- 音频同步高亮 / 逐词跟读（ADR-0015 已否决，需后端时间戳）。
- 整本连读 / 自动翻页 / 自动滚动（与选区作用域定位冲突）。
- ⏮/⏭ 句跳转（依赖句边界时间戳，ADR-0015 未采纳分句合成）。
- 后台 / 锁屏播放（纯浏览器标签限制）。
- 改动 TTS / 音标架构（仅新增面内控制与迷你播放器 UI）。
