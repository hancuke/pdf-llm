## Agent skills

### Issue tracker

Issues are tracked as GitHub Issues in `hancuke/pdf-llm`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels are used as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: a root `CONTEXT.md` plus `docs/adr/` for decisions. See `docs/agents/domain.md`.
